## Story 10 – Model Training and Evaluation

In this story, I worked on building and evaluating a basic machine learning model using the Titanic dataset. After completing the data cleaning in the previous story, I used the processed dataset to train a Logistic Regression model.

First, I split the dataset into training and testing sets using an 80/20 ratio. The model was trained on the training data and then used to make predictions on the test data. To evaluate the model performance, I calculated the accuracy score and also created a confusion matrix to understand how well the model is predicting both survived and not survived passengers.

In the next part, I focused on evaluating the model using additional metrics such as precision, recall, and F1 score. These metrics helped in getting a deeper understanding of the model performance beyond just accuracy. I also generated a classification report which summarizes all these metrics for both classes.

Overall, this story helped me understand how to train a simple classification model and evaluate it properly using different performance metrics. I learned that F1 score is more reliable than accuracy in this case because it balances both precision and recall.
