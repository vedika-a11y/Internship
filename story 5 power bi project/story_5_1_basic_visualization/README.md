# Story 5.1 – Setup & Basic Visualization

## Objective
The objective of this task was to understand the basics of Power BI by creating a simple interactive dashboard using a cleaned dataset.


## Tools Used
- Power BI Desktop


## Steps Performed

1. Installed Power BI Desktop.
2. Imported the cleaned CSV dataset into Power BI.
3. Explored different views:
   - Report View
   - Data View
   - Model View
4. Created multiple visuals to understand the data.
5. Added slicers for interactivity.
6. Designed a single-page dashboard.


## Visualizations Created

1. **Bar Chart**
   - Used to compare total sales across different countries.
   - Helps identify top-performing regions.

2. **Line Chart**
   - Used to analyze sales trends over time (Year/Month).
   - Helps in understanding growth patterns.

3. **Pie Chart**
   - Shows the distribution of total sales by country.
   - Helps in understanding contribution percentage.

4. **Table**
   - Displays detailed data including country, quantity, and sales.
   - Useful for detailed analysis.

5. **KPI Card**
   - Displays total sales.
   - Provides a quick summary of overall performance.

---

## Slicers Used

1. **Date Slicer**
   - Allows filtering data based on time.
   - Helps analyze trends for specific periods.

2. **Category / Country Slicer**
   - Allows filtering by country or category.
   - Helps in focused analysis.


## Business Insights

- Identified top-performing countries contributing maximum sales.
- Observed sales growth trend over time.
- Understood distribution of sales across different regions.
- Enabled dynamic filtering for better decision-making.



## Outcome

- Successfully created a one-page interactive dashboard.
- All visuals respond to slicers.
- Dashboard provides both summary and detailed insights.


## Conclusion

This task helped in building a strong foundation in Power BI, including data loading, visualization creation, and dashboard interactivity. It also improved understanding of how visualizations support business decision-making.
