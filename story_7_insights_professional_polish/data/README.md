Story 7 – Insights & Dashboard Enhancement
Objective

In this phase of the project, I focused on improving the existing dashboard by adding time-based analysis, refining the design, and extracting meaningful business insights. The goal was to make the dashboard more useful for understanding performance and supporting decision-making.

 Dataset Used

I worked on a cleaned Walmart sales dataset which includes information such as store, department, weekly sales, holiday indicators, and some external factors like temperature and fuel price.

⚙️ What I Did
1. Data Preparation

I first ensured that the dataset was properly loaded into Power BI and all columns had the correct data types. The date column was especially important, so I fixed it carefully to enable time-based analysis.

2. Time-Based Analysis

To analyze trends over time, I created additional columns like year, month, and quarter. I also created a separate date table and connected it with the main dataset to support calculations like year-over-year and month-over-month growth.

3. Measures Created

I created a few important measures to understand the data better:

Total Sales
Average Weekly Sales
Holiday Sales

For deeper analysis, I added:

Year-over-Year (YoY) Growth
Month-over-Month (MoM) Growth
Running Total Sales
Top 5 Stores based on sales

These helped in understanding both overall performance and trends.

4. Dashboard Design

I designed the dashboard in a way that it is easy to read and not cluttered.

Page 1 (Overview) shows:

Key metrics at the top
Sales trend over time
Running total of sales
Top performing stores
Department-wise performance

Filters were added so that the user can interact with the dashboard easily.

5. Insights and Business Understanding

In the second page, I focused on understanding what the data is actually telling.

I identified patterns such as:

Some stores contributing more to total sales
Variation in sales across time
Impact of holidays on performance
Differences in department performance

Based on these observations, I also suggested possible actions that a business can take.

 Key Outcome

Through this dashboard, I was able to:

Analyze sales trends over time
Identify top-performing stores and departments
Understand the impact of holidays
Present insights in a clear and simple way
